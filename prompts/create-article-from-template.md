# Задача

Создай новую SEO-статью для блога zoomliontrade.ru на основе шаблона:

templates/article.js

## Входные данные

Тема:
[ВСТАВИТЬ ТЕМУ]

Ключевые слова:
[ВСТАВИТЬ КЛЮЧЕВЫЕ СЛОВА]

Категория:
[Погрузчики / Подъемники / Сервис]

## Что нужно сделать

1. Создать slug латиницей.
2. Создать файл:

content/blog/<slug>.js

3. Взять структуру из templates/article.js.
4. Заполнить поля:
   - slug
   - title
   - description
   - excerpt
   - category
   - date
   - image
   - content

5. В image указать:

/blog/<slug>.webp

6. Добавить статью в:

content/blog/index.js

7. Текст писать на русском языке.
8. Использовать ключевые слова естественно.
9. Не переспамливать.
10. После создания проверить:

npm run build
