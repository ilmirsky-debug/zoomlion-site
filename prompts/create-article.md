# Задача

Создай SEO-статью для сайта zoomliontrade.ru.

## Входные данные

Тема статьи:
[ВСТАВИТЬ ТЕМУ]

Ключевые слова:
[ВСТАВИТЬ КЛЮЧЕВЫЕ СЛОВА]

Категория:
[Погрузчики / Подъемники / Сервис]

## Что нужно сделать

1. Создать новый файл статьи в папке:

content/blog

2. Название файла сделать латиницей, например:

kak-vybrat-nozhnichnyj-podemnik.js

3. Внутри файла использовать формат:

export const article = {
  slug: "...",
  title: "...",
  description: "...",
  excerpt: "...",
  category: "...",
  date: "YYYY-MM-DD",
  image: "/hero1.png",
  content: [
    "...",
    "...",
    "..."
  ],
};

4. Статья должна быть на русском языке.
5. Текст должен быть полезным для клиента, без воды.
6. Длина статьи: 800–1500 слов.
7. В тексте естественно использовать ключевые слова.
8. Не переспамливать ключевые слова.
9. Добавить новую статью в файл:

content/blog/index.js

10. Проверить, что новая статья появилась на /blog.

## Стиль

Писать простым языком для владельцев складов, строительных компаний, производств и отделов снабжения.

Тон: экспертный, спокойный, коммерческий.
